# Video 01 — Thumbnail Brief

## Objective

Make the subject instantly clear: Linux running on a Windows PC. The thumbnail should create curiosity without implying that Windows is being replaced or that WSL is a full separate desktop.

## Recommended concept

**Main visual:** A Windows desktop/laptop screen represented on one side, with a clean Linux terminal window emerging or layered beside it.

**Main text:** LINUX ON WINDOWS?

**Secondary visual:** A compact WSL 2 label or small Ubuntu terminal cue. Avoid adding a second sentence.

## Composition

- 16:9 thumbnail.
- Strong central subject that remains readable at small size.
- Dark charcoal background.
- Electric cyan / icy blue highlights.
- Small restrained green terminal cursor or command-output accent.
- A few subtle binary digits or digital particles to connect to BitBlock's identity.
- Clear separation between the Windows side and Linux terminal.
- Use large, bold typography with generous spacing.
- Do not place important text too close to the edges.

## Text hierarchy

1. LINUX
2. ON WINDOWS?
3. Small WSL 2 identifier

The title already contains the full topic, so the thumbnail should not repeat a long sentence.

## Avoid

- Generic gaming/esports visuals.
- Excessive neon glow.
- Tiny terminal text that looks like unreadable decoration.
- Fake Windows or Ubuntu interface details that look like a real screenshot.
- Claims such as "FULL LINUX PC" or "NO VM" because they are misleading.
- Too many logos or labels.
- A stock photo of a random person at a computer.

## Image-generation / design prompt

Create a high-contrast 16:9 YouTube thumbnail for a technology video titled "Linux on Windows?". Show a modern dark Windows desktop environment with a clearly visible Ubuntu-style Linux terminal window layered prominently in the foreground, visually communicating that Linux tools can run alongside Windows. Use a deep charcoal background, electric cyan and icy blue rim lighting, restrained neon green terminal accents, and a few subtle binary digits fading into the background. The composition should be bold, clean, modern, and readable at small sizes. Leave clear negative space for large text reading "LINUX ON WINDOWS?" and a small "WSL 2" label. Keep the terminal as a visual symbol rather than filling it with tiny unreadable code. Premium technology-channel aesthetic, not gaming or esports. No people, no watermark, no extra text, no mockup frame.

## Final thumbnail check

- Does the subject read in one second?
- Is "LINUX ON WINDOWS?" readable at small size?
- Does the image accurately represent the actual video?
- Is the WSL 2 label correct?
- Does the thumbnail match BitBlock's dark cyan visual identity without becoming cluttered?

# BitBlock Videos

This folder contains the production workspace for individual BitBlock uploads.

Each video gets its own numbered folder. Keep planning, scripts, research, capture notes, editing guidance, and publishing assets together so the video can be produced without hunting through unrelated documents.

## Video folders

- [01 — How to Install Linux on Windows with WSL 2](01%20-%20Linux%20on%20Windows%20with%20WSL%202/README.md) — first-video explainer, installation walkthrough, and practical demonstration package. **Current stage: editing; the creator reports only a little editing remains.**

## Folder conventions

A video folder may contain:
- README.md — creative brief, scope, status, and production decisions.
- SCRIPT.md — narration draft with visual cues.
- SHOT_LIST.md — exact screen captures and supporting visuals to record.
- EDITING_PLAN.md — pacing, structure, graphics, audio, and export notes.
- THUMBNAIL.md — thumbnail concept and generation/design brief.
- PUBLISHING.md — title, description, tags, chapters, and upload checklist.
- FACT_CHECK.md — technical claims, verification notes, and sources.
- RECORDING_CHECKLIST.md — practical capture and privacy checks.

These are working documents. Update them when the actual recording or edit reveals something different. Never claim footage, tests, or results exist until they have been captured and verified.

# BitBlock Tech

## Scope
BitBlock covers technology broadly. It is a tech-only channel and does not need a gaming connection. Subjects may range from beginner-friendly concepts to deeper project development.

## Topic areas
- Software development: programming languages, frameworks, project structure, debugging, and developer workflows.
- Linux: distributions, shell basics, permissions, services, filesystems, and practical administration.
- Windows development: WSL, terminals, system tools, and cross-platform workflows.
- Containers and infrastructure: Docker, Compose, VPS concepts, servers, self-hosting, and networking.
- AI for developers: APIs, coding assistants, local models, model trade-offs, and responsible use.
- Automation: scripts, workflow improvements, desktop utilities, and repeatable tasks.
- Hardware and homelabs: practical hardware choices, small servers, peripherals, and experiments.
- Cybersecurity education: defensive fundamentals, safe lab concepts, account security, and privacy.
- Original software and technical projects, including ATLAS and mod development.

## Early video approaches
The channel should use a varied mix of:
- **Beginner tutorials** that explain a tool, concept, setup, or workflow accessibly.
- **Documented experiments** that begin with a question and honestly show the method, result, surprises, and limitations.
- **Interesting workflows** that demonstrate a useful way to combine tools or automate a task.

These approaches are complementary, not separate channel strategies. A single video may combine them. Do not make the channel tutorial-only.

## Video approaches
Tutorials, explainers, experiments, workflow demonstrations, project development diaries, planning/design episodes, and reviews based on actual use are all suitable.

## Quality bar
State the tested environment and versions where they matter. Avoid universal claims based on one machine. Do not publish commands that are unverified or unsafe. Explain risks before actions that change systems.

## Game footage in technical videos
Footage from Minecraft or another game is allowed only when it supports a technical explanation or demonstration—for example, showing a mod feature that has just been developed. The video must remain about the technical work, not gameplay. See the technical game-demonstration guidance.

# Channel Architecture

## Current structure
One YouTube channel: **BitBlock**.

Organise uploads with:
- playlists for Tech and Gaming;
- named playlists for recurring projects or formats;
- consistent series labels in titles or descriptions where helpful;
- channel sections that make the two pillars easy to browse.

## Why one channel first
The channel is new and the actual audience split is not yet known. Starting with multiple channels adds overhead and makes it harder to build a consistent publishing habit. One umbrella channel allows experimentation while preserving the option to split later.

## Possible future structure
If evidence supports a split, the brand could evolve into:
- BitBlock Tech — software, development, AI, Linux, servers, tools, hardware, and wider technology.
- BitBlock Gaming — Minecraft and other gaming.

This is a possible future, not a launch commitment.

## Split checklist
Before splitting, review a meaningful sample of uploads and ask whether each pillar has a stable audience, sufficient ideas, sustainable production capacity, and a clear reason to exist independently. Plan how existing videos and subscribers will be handled before acting.

## Naming and consistency
Do not use sub-brand names in a way that makes viewers think separate channels already exist. The main channel remains BitBlock until a deliberate change is made.

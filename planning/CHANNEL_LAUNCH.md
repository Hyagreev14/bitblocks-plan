# Channel Launch Plan

## Goal
Launch BitBlock with a clear technology-focused identity and enough prepared ideas to avoid starting from a blank page. The launch should be simple and achievable.

## Before the first upload
- Finalise a usable profile image and banner.
- Write a channel description that reflects technology, software development, and practical experimentation.
- Set up basic channel sections and playlists when content exists.
- Choose an initial technical video idea that can be completed with available tools and time.
- Test voice recording and editing with a short sample.
- Check that captures and assets do not expose private information.

## First content mix
There is no required format ratio. Early videos can include beginner tutorials, documented experiments, and interesting workflows. These are complementary approaches; the channel should not become tutorial-only. WSL and Docker Desktop are examples of current tools that may feature, not a fixed launch list. The exact first topics and release order remain undecided.

BitBlock does not publish gameplay-focused videos. Game footage may be used only when it directly demonstrates a technical subject, such as a mod feature.

## Launch video options
Potential introductions include:
- a strong standalone Tech video that demonstrates the channel's style;
- a useful tutorial, experiment, or workflow based on a genuine question;
- an ATLAS introduction only if the project is ready to be presented clearly.

ATLAS is not intended to be the required launch content. A channel introduction is optional. A useful video can introduce the channel better than a generic announcement.

## After launch
Focus on making the next video. Use early feedback as information, not as a verdict. Adjust packaging and pacing gradually. Do not invent a fixed upload frequency or force topics to fill a schedule.

# Timelapse Capture

## Purpose
Capture the development of ATLAS without recording continuous desktop video. A Chronolapse-style screenshot tool periodically captures the workspace; the images are later assembled into a timelapse.

## Starting interval
Test an interval of roughly **5–10 seconds**. A shorter interval captures more detail but creates more images and storage use. A longer interval creates a lighter sequence but may miss short changes. Choose based on the pace of the session and test results.

## Capture preparation
- Choose a dedicated folder for each session.
- Capture only the intended monitor or application area where possible.
- Close unrelated windows and notifications.
- Use a clean workspace layout that makes the code or design readable.
- Avoid displaying secrets, personal information, private messages, or unrelated files.
- Confirm available disk space and test a short capture before a long session.

## During the session
Work normally. Do not change your workflow just to make the timelapse look busy. If a session includes long breaks, pause capture if convenient. Optional notes can mark important moments such as a feature starting, a bug being investigated, a decision changing, or the session ending.

## After the session
1. Review the image sequence.
2. Remove or exclude frames containing private information.
3. Check that the sequence is in the correct order.
4. Assemble the frames into a video.
5. Adjust playback speed so important work is visible without making the video unnecessarily long.
6. Add zooms, crops, or cutaways where small text would otherwise be unreadable.
7. Sync the sequence with the voiceover.

## Limitations
A screenshot timelapse cannot show every interaction clearly. The narration must explain important changes. Use separate diagrams or brief direct screen captures only when they materially improve understanding.

## Storage
Keep raw captures only as long as useful for editing or project history. Organise by project and session, and avoid committing large raw image folders to the public planning repository.
